# Security Policy

## Supported Versions

This is a template repository, so security fixes are generally applied to the latest version on the default branch.

If you are using a fork or an older copy, you may need to manually apply fixes.

## Reporting a Vulnerability

Please do not open public issues for sensitive vulnerabilities.

Instead:

- use GitHub private vulnerability reporting if available
- or contact the repository owner privately through GitHub

Please include:

- a description of the issue
- reproduction steps
- affected files or routes
- possible impact

## Scope

This policy primarily covers:

- studio authentication
- session handling
- API routes
- content persistence
- deployment guidance in the documentation

## Notes

- GitHub Pages deployments are static previews only
- secure studio behavior requires the Node server to run
- users deploying this template are responsible for configuring strong secrets, credentials, and hosting security
