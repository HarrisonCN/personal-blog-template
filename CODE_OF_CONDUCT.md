# Code of Conduct

## Our Pledge

We want this project to be an open, welcoming, and respectful space for everyone.

Contributors, maintainers, and participants are expected to make participation in this project harassment-free for everyone, regardless of age, body size, disability, ethnicity, gender identity or expression, level of experience, education, nationality, personal appearance, race, religion, or sexual identity and orientation.

我们希望这个项目对所有人都是开放、友好且尊重的协作空间。

## Expected Behavior

- Be respectful in language and tone.
- Assume good intent, but communicate clearly.
- Offer constructive feedback.
- Focus on improving the project, not attacking people.
- Respect different skill levels and backgrounds.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language
- Personal attacks or insults
- Publishing private information without permission
- Trolling, bad-faith arguments, or deliberately disruptive behavior
- Sexualized language or unwelcome advances

## Maintainer Responsibilities

Project maintainers may remove, edit, or reject comments, commits, issues, pull requests, discussions, and other contributions that violate this Code of Conduct.

Maintainers may also temporarily or permanently ban contributors for repeated or severe misconduct.

## Scope

This Code of Conduct applies within:

- GitHub issues
- pull requests
- discussions
- documentation
- community interactions directly related to this repository

## Reporting

If you experience or witness unacceptable behavior, open a private report through GitHub or contact the maintainer through the repository owner account.

Please include:

- what happened
- where it happened
- links or screenshots when available
- any context that helps explain the situation

Reports will be reviewed as promptly and fairly as possible.

## Enforcement

Possible responses include:

- a warning
- removal of content
- temporary suspension from community spaces
- permanent removal from participation in this project
